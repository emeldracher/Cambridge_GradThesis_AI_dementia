coopercare-backend includes the node and backend guidelines for the OpenAI API request. 

When my great-aunt asked me when her husband was coming home,  for the third time, I redirected the conversation (instead of saying he died 12 years earlier). These are the nuances that LLMs must understand when working vulnerable populations. To tackle this need, and the growing demand for caregivers, I built CooperCare, an AI canine companion for people living with dementia. 

This was my Master's thesis, and continued work, from the University of Cambridge. I developed an iOS app that used OpenAI's API to respond to users in a canine and friendly way. With every input, an entire backend set of guardrails was sent through the API to avoid triggering the user. A tab in the application allowed caregivers to add long-term notes (such as when a relative passed). Every request sent to the API included the past 20 messages to preserve context in discussion. The app also set reminders to the phone based on casual or typed conversation. This entire work included Swift, Node.js + Express, JSON, and GPT-4.1-mini elements. Puppy-like responses were encouraged to avoid condescension to users. Prior iterations included an Amazon Alexa skill with an AWS and OpenAI connection. 

With every input into the app (either spoken or typed), an entire backend set of guardrails was sent through the OpenAI API to avoid triggering the user. These guidelines were made using prior professional research in working with people with dementia. From journal articles to NHS suggestions, I hand-transcribed "do's" and "don'ts" in various scenarios, and put them into the backend of every message. These guidelines themselves were tradeoffs in that I had to include safety precautions 3 times to alert humans in any danger. I hand-transcribed 200 dementia scenarios from online public videos and websites. Then, I used binary scoring scales (0 = no, 1 = yes) to assess whether AI responses directly addressed the user, validated emotions, encouraged follow-up conversation, demonstrated empathy, and violated dementia communication guidelines. I also calculated readability using Flesch Reading Ease (typically 0–100, higher is easier) and Flesch–Kincaid Grade Level (US school grade equivalent). Each score was hand-recorded for a human's response, the suggested human response (from professional websites), classic ChatGPT, and the application I had made.
